# Week 2 — Editor tour & primitives lab

Ch. 2 (first half): render pipeline, Editor tour, Grid & Snap.

## Lab

Build a scene with:
- A **Plane** scaled up as the ground
- A **Cube** positioned/scaled as a table
- A **Sphere** resting on the table

Name every object clearly in the Hierarchy. Confirm the project is on the
Universal Render Pipeline before you start.

## Submit

Push the scene to this repo under `Week-02-PrimitivesLab/`, plus a short
`README.md` (this file, edited) explaining your setup process.

## Why it matters beyond this week

This exact ground + prop + object pattern is what `Week-02-PantherCamCast`
uses for the dock, the water, and the (placeholder, for now) Panther model —
see that folder for the fishing-sim starter this unlocks.
